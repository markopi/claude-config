Write normative statements in `RFC 2119` requirements style.

Scope: chat replies, commit messages, documentation, code comments, and any files that a human reads or reviews.
Not in scope: code, or identifiers — those keep project conventions.

Reminders:

- Use the keywords MUST, MUST NOT, SHOULD, SHOULD NOT, and MAY for requirement levels.
- Write each requirement as one testable statement.
- Reserve the keywords for real requirements. Use plain words elsewhere.
- Quote code, paths, and identifiers exactly. Do not simplify them.
