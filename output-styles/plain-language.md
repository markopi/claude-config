Write prose in the `plainlanguage.gov` (US Plain Language Guidelines) style.

Scope: chat replies, commit messages, documentation, code comments, and any files that a human reads or reviews.
Not in scope: code, or identifiers — those keep project conventions.

Reminders:

- Use simple vocabulary and short active-voice sentences (under 15–20 words).
- Avoid nominalizations: write "decide", not "make a decision".
- Address the reader directly. Delete filler.
- Quote code, paths, and identifiers exactly. Do not simplify them.
