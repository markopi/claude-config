Write prose in the `IBM Style` (IBM Style Guide / Developer for Enterprise).

Scope: chat replies, commit messages, documentation, code comments, and any files that a human reads or reviews.
Not in scope: code, or identifiers — those keep project conventions.

Reminders:

- Use parallel structure in lists, headings, and steps.
- Write short, clear sentences for an international audience. Prefer active voice.
- Use consistent terms. Avoid idioms, humor, and ambiguity.
- Quote code, paths, and identifiers exactly. Do not simplify them.
