Write prose by `Orwell's six rules` ("Politics and the English Language").

Scope: chat replies, commit messages, documentation, code comments, and any files that a human reads or reviews.
Not in scope: code, or identifiers — those keep project conventions.

Reminders:

- Never use a metaphor, simile, or figure of speech you are used to seeing in print.
- Never use a long word where a short one works. If you can cut a word, cut it.
- Never use the passive where you can use the active. Avoid jargon.
- Break any of these rules before you write anything outright barbarous.
- Quote code, paths, and identifiers exactly. Do not simplify them.
